## 0. 三十秒版本

> 開一個專案時，先選好「大家最後要用哪種錢結帳」（**結算幣別**），**不用設匯率**。
> 之後新增支出時選這筆的幣別：
> - 跟結算幣別一樣 → 什麼都不用管。
> - 不一樣 → 系統自動帶入「**當下匯率**」，你也能改。
>
> 你輸入金額和誰分、誰先付，都用**這筆的原幣**；旁邊同時顯示「**大約等於多少結算幣別**」。
> 存檔那一刻，系統把金額換成結算幣別、**配成整數**（除不盡的零頭用一套公平規則分掉，並記帳）。
> 從此**列表、統計、誰欠誰，全部只看結算幣別**，結帳時不用再換算。
> 之後想改某一筆的匯率也可以，系統會把那筆重算、帳面也修正。

## 1. 最核心的規則：先換錢，再分帳

**白話**：先把整筆錢換成「結算幣別」，再在結算幣別上分給大家。**不要**先分原幣、之後才各自換成結算幣別。

```
建立一筆支出時：
  ① 記下當下匯率
  ② 整筆金額 → 換成結算幣別 → 取整（例如 31.715 → 31.72）
  ③ 在結算幣別上分給每個人、也記誰付了多少，都配成整數
  ④ 存兩份：原幣（給你看帳單）＋ 結算幣別（真正算帳用）

原幣那一層   → 只是「對帳 / 顯示」，不參與算帳
結算幣別那層 → 才是「權威」，餘額、誰欠誰都看它
```

**為什麼這樣做**
- 換算只做一次，零頭只會出現在一個地方，不容易出錯。
- 符合大家的心裡感覺：「我最後到底要付多少錢」。
- 結帳時金額都已經是結算幣別了，**不用再換算**。

**要你確認的事**
- [ ] 同意「先換成結算幣別，再分帳」
- [ ] 同意「原幣只是拿來看帳單，真正算帳只看結算幣別」

> 小提醒：這裡講的是「**結算幣別**優先」，不是特定某種幣。結算幣別可能是 TWD、USD、EUR…都可以。

## 2. 幾個名詞（白話）

| 名詞 | 白話意思 | 例子 |
|---|---|---|
| 結算幣別 | 這個專案最後用哪種錢結帳（專案建立時選定） | 選 USD，大家就都用 USD 互欠 |

| 綁定匯率 | 建立這筆時記下來的匯率，之後固定不變 | 1 TWD = 0.031715 USD |

| 自訂匯率 | 這筆的匯率跟專案目前設定的不同（只是顯示一個標記） | 顯示「自訂」徽章 |

## 4. 一筆支出實際怎麼算

**白話步驟**（以「TWD 1,000，專案結算幣別 USD，匯率 0.031715」為例）

1. 決定匯率：你指定就用你的；沒指定就照專案設定（固定或即時）。
2. 整筆換算：1,000 × 0.031715 = 31.715 → 取整成 **31.72**（= 3172 分，最小單位 1 分）。
3. 分攤：把 31.72 分給每個人，配成整數。
4. 付款：把 31.72 記在每個出錢的人身上，也配成整數。
5. 存檔：原幣金額 ＋ 結算幣別金額 ＋ 匯率 一起寫進去。
6. 檢查：每個人分到的加起來 ＝ 每個人付的加起來 ＝ 31.72。**一毛不差**。

**要你確認的事**
- [ ] 「分攤」和「付款」兩邊都要各自配成整數（湊到同一個總額）
- [ ] 畫面顯示的是**預估值**，存檔後以系統算的為準（最多差 1 分／人）

## 5. 除不盡的零頭怎麼辦（尾差）

**白話**：31.72 三個人分，會剩零頭（無法每人剛好 10.573…）。我們的做法是「**這次給上次吃虧的人多一點**」，長期下來大家拿到的一樣多。

**規則**
- 每個人身上有一本「尾差帳」：正數＝以前多拿過，負數＝以前少拿過。
- 有零頭要分時，**先分給目前吃虧最多（帳最負）的人**。
- 之後編輯或刪除這筆，會把這筆的零頭「還回去」，再重新分。

**要你確認的事**
- [ ] 同意「零頭優先補給最吃虧的人」這個公平做法
- [ ] 同意編輯／刪除時要修正尾差帳

## 6. 資料怎麼存（白話）

| 存什麼 | 用途 |
|---|---|
| 這筆的原幣金額、原幣分帳、原幣付款 | 給你看帳單、對帳 |
| 這筆的**結算幣別**分帳、付款 | 真正算帳（權威） |
| 這筆綁定的匯率 | 記錄當時用多少換的 |
| 每位成員的尾差帳 | 維持長期公平 |
| 專案設定「預設匯率來源」（固定／即時） | 新支出預設抓哪個匯率 |

- 舊資料（已經存在的支出）會用「當下匯率」補上匯率與結算幣別金額，尾差帳從 0 開始。
- 如果這筆本來就是結算幣別，就不用記匯率（等於沒換）。

**要你確認的事**
- [ ] 結算幣別金額的存放精度用高精度小數（18 位，其中 8 位小數）可以嗎？
- [ ] 同幣別支出不記匯率

## 7. 使用者實際會看到的流程

### 7.1 建立專案
- 輸入名稱、封面、日期、**結算幣別**。
- 選好幣別後，下面出現一行說明：TWD →「四捨五入到整數」；USD →「四捨五入到 0.01」。
- **這時不用設任何匯率。**
- [ ] 確認

### 7.2 專案設定 › 幣別與匯率
- 「**預設匯率來源**」可選 `固定匯率` / `即時匯率`（預設固定）。
  - 固定：新支出自動帶入你設的固定匯率（沒有就自動抓即時的一次）。
  - 即時：新支出自動帶入當下即時匯率。
- 下面列出手動設定的固定匯率（有在用的外幣各一行，可改，也能按「用即時」）。
- 說明「**只影響以後的新支出**」。
- 拿掉以前那個「改了會影響 N 筆、要按兩次確認」的流程。
- [ ] 確認

### 7.3 匯率頁
- 換算器 ＋「設為專案固定匯率」。
- [ ] 確認

### 7.4 新增支出（重點）
- 選幣別：
  - **等於結算幣別** → 不顯示匯率、不用管。
  - **不等於** → 自動帶入匯率，顯示「大約＝多少結算幣別」，可點進去改**這一筆**的匯率。
- 分帳和付款都用**原幣**輸入；每個人下面小字顯示「大約＝多少結算幣別」。
- 如果有人因為零頭被多分 1 分，明細會標「尾差」，避免你覺得加起來怪。
- [ ] 確認

### 7.5 存檔後（系統做的事）
1. 記下匯率。
2. 整筆換成結算幣別並取整。
3. 在結算幣別上分配給每個人（含零頭）。
4. 存檔 ＋ 更新尾差帳（同一時間完成，不會算到一半）。
- [ ] 確認

### 7.6 支出列表／明細
- 顯示「原幣金額」＋「大約＝多少結算幣別」，跟統計、結算一致。
- [ ] 確認

### 7.7 編輯／刪除
- 改匯率／金額／分帳 → 會**修正尾差帳並重算**。
- 改專案的固定匯率 → **不影響**舊支出。
- [ ] 確認

### 7.8 統計
- 直接用**結算幣別**金額加總。
- [ ] 確認

### 7.9 結算
- **不用換算、不會有零頭**：金額都已經是結算幣別，直接算誰欠誰。
- [ ] 確認

### 7.10 匯出
- 給結算幣別（算帳用）＋ 原幣金額 ＋ 當時匯率（對帳用）。
- [ ] 確認

## 8. 金額顯示統一

**白話**：這個幣別平常顯示到幾位，就固定到幾位。TWD／JPY 沒有小數，USD／EUR 到 0.01。不可以有的地方 2 位、有的地方 0 位，看起來像 bug。

- 所有金額顯示都走同一個函式（`formatAmount` / `formatCurrency`）。
- 把目前偷用 `toFixed()`、`toLocaleString()` 的地方收斂過來。
- 幣別名稱太長就截斷，不要擠爆版面。
- [ ] 確認

## 10. 做完的驗收條件

- [ ] 建立專案時，幣別說明會依你選的幣別自動變（TWD 整數 / USD 到 0.01）。
- [ ] 專案設定能切換「預設匯率來源（固定／即時）」，新支出照它帶入匯率。
- [ ] 新增外幣支出：建立時綁定匯率；換算後為整數，加總等於整筆。
- [ ] 分攤／付款在結算幣別下加總相符；尾差帳有更新。
- [ ] 改某筆匯率 → 重算且正確修正尾差帳；刪除 → 正確修正。
- [ ] 改專案固定匯率 → 只影響未來，不用按確認。
- [ ] 結算結果加總 = 0（誰欠誰剛好互抵）；統計／匯出跟結算一致。
- [ ] 顯示統一（TWD 無小數、USD 有美分）；長名稱不跑版。
- [ ] 測試全通過、lint 沒錯誤。

## 12. 這次先不做

- 每筆多段匯率、自動抓歷史當日匯率。
- 部分付款／應收應付。
- 自訂幣別、加密貨幣。
- 跨專案合併的尾差帳。

## 13. 給工程師的細節（可以跳過）

- **欄位**：`Expense.exchangeRate`（Decimal 18,8，同幣別為 null）、`ExpenseParticipant.shareAmountProject`、`ExpensePayer.amountProject`、`ProjectMember.remainderDiscrepancy`（Int）、`Project.rateSource`（預設 `"fixed"`）。
- **計算位置**：伺服器端為唯一權威；前端只做近似預覽（`≈`）。
- **換算**：`totalMinor = roundToMinorUnit(amount × rate)`；分配用 `allocate(totalMinor, weights, discrepancy)`（floor 後，零頭依 discrepancy 由低到高給 +1）。
- **回滾**：`extra_i = 已存 project 值 − floor(exact_i)`，`discrepancy -= extra_i`，再重配；與支出寫入同一交易。
- **不變式**：Σ `shareAmountProject` = Σ `amountProject` = `totalMinor`。
- **結算端**：直接累加 `*Project`，不再換算。
- 完整規格見設計文件 `2026-10-08-multi-currency-expense-design.md`（§4 資料模型、§5 計算流程、§6 演算法）。
