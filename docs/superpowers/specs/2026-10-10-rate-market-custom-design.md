# 匯率面板：收斂為「市場／自訂」（並移除專案固定匯率）設計

日期：2026-10-10
狀態：待實作
取代：`docs/superpowers/specs/2026-10-10-per-currency-fixed-rate-design.md`（逐幣別固定匯率）——**作廢**
相關：`docs/superpowers/specs/2026-10-10-project-settings-rate-ux-design.md`（其固定匯率相關部分連帶作廢）

## 1. 背景與問題

目前「新增支出」的匯率來源有 **4 種字**（`專案` / `即時` / `市場 M/d` / `自訂`），面板有 **3 個 tab**（`即時` / `歷史` / `自訂`）再加一顆「同時設為專案固定匯率」。實測回饋：

- **太多分類、名詞難懂**：`即時` 與 `市場` 其實是同一來源（市場匯率），只差日期。
- **`專案` vs `自訂` 容易混**：兩者都是「人手打的數字」，差別只在**範圍**（整專案 vs 只這一筆），但名字講的是「性質」。
- **`專案固定匯率` 功能太重**：使用率低、卻讓面板與結算都多一層。

決策：**把匯率來源收斂成兩種 —— `市場` / `自訂`**，並**整個移除「專案固定匯率」功能**。

## 2. 目標 / 非目標

**目標**

- 匯率來源**只有兩種**：`市場`（市場／即時匯率）、`自訂`（你指定一個數字）。
- 匯率面板**只有兩個 tab**：`市場` / `自訂`。不再出現「即時／歷史／專案固定匯率」這幾個名字與分類。
  - **市場 tab**：由**日期**決定。預設「今天」（＝即時）；改日期就抓**那一天**的歷史匯率。
  - **自訂 tab**：自己輸入數字，或從「**最近用過的匯率**」清單**沿用**；沿用一律**算成自訂**。
- 金額卡標籤只剩 `市場（＋日期）` 與 `自訂`。
- **整個移除「專案固定匯率」**：專案設定、結算偏好、記帳當下 promote、AI 快速記帳勾選、匯率頁顯示、匯出／總覽、V1 介面、資料庫欄位。

**非目標**

- 不改最小單位、精度、尾差／整數分配演算法（**只改「匯率從哪來」，不改金額怎麼分**）。
- 不改既有支出已存的金額與快照。
- 顯示幣別維持**幣別代碼**（`TWD`／`JPY`），不改成 `NT$`／`¥`。

## 3. 模型

- `ExpenseRateKind`：由 `"project" | "market" | "custom"` → **`"market" | "custom"`**（移除 `project`）。
- `resolveRate`：`provided ?? live`（移除 `customRate` 分支與 `fixed` 來源）。
- `resolvePreviewRate`：`source` 由 `"same" | "fixed" | "live" | "none"` → **`"same" | "live" | "none"`**。
- `resolveExpenseRateMeta`：`kind = provided ? (clientKind ?? "custom") : "market"`（移除 `hasProjectFixedRate`）。
- 結算：`exchangeRatesUsed[c] = 即時匯率`（移除 `customRates[c] ?? …` 偏好）；`summary` 移除 `usingCustomRates` / `hasCustomRates`。
- **新支出預設**：外幣 → 今天的市場匯率（＝即時）。沒有任何「專案固定值優先」。
- **舊資料**：既有 `rateKind === "project"` 的支出，**數字不變**，顯示上歸為 **`自訂`**（Phase 3 可選擇資料遷移；在此之前以顯示映射處理）。

## 4. UI

### 4.1 匯率面板（新增／編輯支出）

- **2 個 tab**：`市場` / `自訂`。
- **市場 tab**
  - 一個**日期欄**，預設＝今天。
  - 今天 → 顯示今天的**即時**匯率（＋「更新於 …」）。
  - **改日期 → 自動抓那天**的歷史匯率（含讀取中／查不到那天的錯誤訊息與重試）。
  - 相符的「使用」鈕綁定該筆。
  - 說明字：今天＝「預設就是今天」；非今天＝「你改了日期，這是歷史匯率」。
- **自訂 tab**
  - 輸入框，**預填「最近用過的匯率」**（本專案、同幣別組合；市場或自訂皆可）。標示「**✎ 自動帶入你最近用過的匯率**」，讓使用者看得出是沿用、可清掉。
  - 清單標題：**最近用過的匯率（這個專案 · `FROM`→`TO`）**。
  - 每列：**數字** ＋ **來源小標**（`市場` / `自訂`）＋ **日期** ＋ **哪一筆支出**。點「沿用」→ 套用到本筆，**一律算成 `自訂`**。
  - 說明字：沿用時提示「✓ 沿用 X（這一筆會算成「自訂」）」。
  - 說明「自訂只影響這一筆，不會改動專案設定」。
- **移除**：`專案固定匯率` 提示、`同時設為專案固定匯率` 開關列、`projectFixedRate` prop。
- **保留**：`還原預設`（回到市場／今天）。

### 4.2 金額卡標籤

- `rateChip` 只剩兩種色系（`market` / `custom`）：
  - 市場今天 → `市場 · 今天`
  - 市場某天 → `市場 · M/d`
  - 自訂 → `自訂`
- 移除 `project` tone。

### 4.3 AI 快速記帳

- 移除金額卡自訂匯率列下方的「設為專案固定匯率」勾選；其餘沿用同一面板／邏輯。

### 4.4 結算顯示

- 移除「使用自訂匯率結算」字樣，一律顯示「使用即時匯率結算」；移除逐幣別「（自訂）」標記。

### 4.5 專案設定（Phase 2）

- 移除「固定匯率（選填）」區塊與其面板（新增／移除固定幣別）。

### 4.6 匯率頁（Phase 2）

- 移除「專案自訂匯率」區塊與其對比。

### 4.7 匯出 / 專案總覽（Phase 2）

- 移除 `customRates` 的使用（改以即時／每筆為主）。

## 5. 資料 / 介面

- **Phase 1（停止使用）**：新增／編輯支出、結算、匯率面板、AI 快速記帳、金額卡標籤、`rateMeta` 都**不再讀寫 `customRates`**。DB 欄位**保留但不再使用**。
- **Phase 2（移除 UI）**：專案設定、匯率頁、匯出、總覽移除 `customRates` UI。
- **Phase 3（清除）**：
  - 移除 API payload 的 `promoteRate`、專案 PUT 的 `customRates`、`rateSource`（若仍在）。
  - 清除舊版 V1 的 `customRates` 參照。
  - **遷移**刪除 `Project.customRates` 欄位。
  - 既有 `rateKind === "project"` 的支出：資料遷移為 `custom`（或維持顯示映射）。
- **「最近用過的匯率」清單資料**：需要「本專案、同幣別組合、最近 N 筆（建議 5）外幣支出」的匯率（值＋`rateKind`＋`rateDate`＋描述）。實作方式（伺服器查詢或隨專案資料預載）留給實作計畫。

## 6. 測試計畫

- 純函式：`resolveRate` / `resolvePreviewRate` / `resolveExpenseRateMeta` 去 `project` 後各分支。
- 匯率面板：2 tab 存在；市場改日期 → 走歷史；自訂預填最近用過的值；清單含市場＋自訂、來源小標正確；沿用後 `rateKind` 為 `custom`。
- 金額卡標籤：`市場 · 今天` / `市場 · M/d` / `自訂`。
- 結算：不再使用 `customRates`（改用即時）；平衡（`isBalanced`）不變；既有快照金額不變。
- 舊資料：`rateKind === "project"` 的顯示映射。
- AI 快速記帳：無「設為專案固定匯率」。
- 全套 `npm run test:run` ＋ `npm run lint`。

## 7. 決策記錄

- **4 類 → 2 類**（`市場` / `自訂`）。
- **市場＝日期決定**（今天＝即時、改日期＝歷史）；不再有「即時／歷史」兩個 tab 與名稱。
- **自訂＝你指定一個數字**；清單沿用「最近用過的匯率」**含市場**，沿用**一律算自訂**。
- **整個移除「專案固定匯率」**（分 3 階段）。
- 大方向來自與使用者的對話；顯示維持**幣別代碼**。

## 8. 分階段（實作順序）

- **Phase 1（核心、最有感）**：匯率面板 2 tab ＋ 金額卡標籤 ＋ 建立／結算不再用 `customRates` ＋ AI 移除 promote ＋ 結算字樣。
- **Phase 2**：專案設定、匯率頁、匯出、總覽移除 `customRates` UI。
- **Phase 3**：API 清理 ＋ V1 ＋ DB 欄位遷移刪除（＋ 舊 `rateKind` 遷移）。
