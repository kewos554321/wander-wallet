# 專案匯率：逐幣別固定（預設即時）設計

日期：2026-10-10
狀態：待實作
取代：`docs/superpowers/specs/2026-10-09-project-rate-source-design.md`（專案層級「固定 / 即時」總開關）——**作廢**
部分取代：`docs/superpowers/specs/2026-10-10-project-settings-rate-ux-design.md`（其匯率 tab 相關作廢；最小單位、移除精度、新增預填仍有效）

## 1. 背景與問題

先前模型有兩層：**專案層級 `rateSource`**（`fixed`／`live` 總開關）＋ **逐幣別 `customRates`**。實測後發現：

- **tab 語意矛盾**：在「專案固定匯率」模式下，**沒設定固定值的幣別仍走即時**（例如 `EUR 即時`）→「固定模式下卻出現即時」很怪。
- 真相是：**狀態本來就是逐幣別**（「這個幣別有沒有固定值」），不是一個專案層級的二選一。tab 把「事實」和「意圖」混在一起。
- 而且對多數人（LINE 休閒記帳）來說，**即時匯率才是合理預設**；固定匯率是少數人、少數幣別才需要的。

## 2. 目標 / 非目標

**目標**

- **專案預設＝即時匯率**：任何沒被設成固定的幣別，一律即時。
- **固定匯率＝逐幣別 opt-in**，兩個入口：
  1. **專案設定**：新增／編輯／**移除**固定幣別。
  2. **記帳當下**（新增／編輯／AI 結果）：使用自訂匯率時，可順手**「設為專案固定匯率」**。
- 其餘一律即時。
- **移除專案層級 tab 與 `rateSource` 概念**。

**非目標**

- 不改結算（用已存快照）。
- 不改最小單位、精度移除、匯率面板的即時/歷史/自訂 tabs。
- 不改既有支出金額。

## 3. 模型

- 每個外幣 `c`：**有 `customRates[c]` → 用固定；否則用即時**。
- 新支出的換算：`customRates[currency] ?? 即時`。
- **沒有 `rateSource`**：不再有全專案的固定/即時切換。
- 自動 seed 已移除（不會偷偷把即時寫成固定）。

## 4. UI

### 4.1 專案設定「幣別與匯率」
- **結算幣別**（＋ 說明 ＋ 最小單位）。
- **固定匯率（選填）**：
  - 清單**只列「加過」的幣別**（不再列出每個用過的幣別成「即時」）。
  - 每列：`JPY　0.21 TWD　›`。
  - 空狀態：`未設定。新支出一律使用即時匯率。想固定某個幣別再新增。` ＋ `＋ 新增固定匯率`。
  - 點列 → **面板**：改值，或 **`改用即時`（＝移除該固定值）**。
  - `＋ 新增固定匯率` → 選幣別、自動帶入當下即時匯率（6 位有效數字）、可改。

### 4.2 匯率面板（支出表單）
- 在 `完成` 上方加**開關列**：`☐ 同時設為專案固定匯率`，副標 `之後 {幣別} 的新支出都會用這個值`。
- **預設關閉**；不勾＝維持只影響這一筆（現行行為）。
- 該幣別**已有固定值** → 勾選後提示 `{幣別} 目前已有固定匯率 X，完成後會覆蓋為 Y。`
- **只有勾了且按「完成」才寫入專案**。

### 4.3 AI／快速記帳
- 沒有匯率面板 → 同一個開關列放在**金額卡的自訂匯率列下方**。

### 4.4 移除
- 在專案設定清單點該列 → 面板 `改用即時`（移除）。

## 5. 資料 / 介面

- `Project.rateSource`：**不再使用**（欄位保留，之後可清）。
- `effectiveCustomRates`（live 模式覆寫）：**不需要** → 停用/移除。
- `resolveRate`：**簡化**，不再看 `rateSource` → `customRates[c] ?? live`。
- **新能力**：把「本筆的匯率」寫入 `Project.customRates[c]`。**建議做法**：擴充支出 create/edit 的 payload（`promoteRate?: boolean`），伺服器在**同一交易**把該幣別的固定值寫入 `Project.customRates`；AI／快速記帳走同一條。（替代：另開一支小 endpoint 重用專案 PUT 的 `customRates`。）
- 既有支出不變（凍結快照）。

## 6. 測試計畫

- `resolveRate`：去 `rateSource` 後各分支。
- 設定頁：只列加過的幣別、新增（帶入即時）、移除（改用即時）、空狀態。
- 匯率面板：開關預設關；勾選＋完成 → 寫入 `customRates`；已有值 → 覆蓋提示；不勾 → 不寫專案。
- AI 卡片：同上。
- `settle` / 預覽：`customRates[c] ?? live`。
- 全套 `npm run test:run` ＋ `npm run lint`。

## 7. 決策記錄

- **不用 tab**；**專案預設＝即時**；**固定匯率＝逐幣別 opt-in**。
- **升級入口**：專案設定 ＋ 記帳當下（面板開關列 / AI 卡片開關）。
- **移除**在專案設定（面板「改用即時」）。
- 固定值以 **6 位有效數字**顯示與儲存。
