> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 v2 token-only 呈現層補上 6 個尚未開發的畫面（A24 筆記、A25 照片牆、A23 匯出、A15 匯率、A22 歷史紀錄、A16 消費地圖），route 以 `UiVersionSwitch` 切換，v1 行為不變。

## Review Focus

1. **A23 匯出遇多幣別但匯率尚未載入** → 換算不得產生 `NaN`／`0`，應以自訂匯率或退回原值（Task 9）。
2. **A15 匯率 `from === to` 或缺少 rate** → 換算穩定、顯示不 `NaN`，交換鈕可連按（Task 12／13）。
3. **A25 燈箱邊界** → 第一張按上一張、最後一張按下一張要 wrap；篩選後為空時不得開啟燈箱而崩潰（Task 7）。

5. **A16 零筆有座標的消費** → 顯示空狀態，不渲染/不崩於地圖（Task 19）。
6. **A24 memo 為 null／空字串** → textarea 空白、儲存鈕停用（Task 5）。
