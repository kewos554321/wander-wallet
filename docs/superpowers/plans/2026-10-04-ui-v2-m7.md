# UI v2 里程碑 7（v20261004 delta）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Align the already-shipped v2 screens to the v20261004 design delta (plus new boards for A3f/A8b/A21/A26/A27/A10-A12), without touching v1.

**Architecture:** Presentation-only changes inside `components/v2/**` plus additive tokens in `app/globals.css`. One new v2 calculator pad and two new v2 settle dialogs replace uses of v1-shared components from the v2 side (v1 keeps the shared files). Quick-expense A12b reuses the A3 form components.

**Tech Stack:** Next.js (App Router), React 19, TypeScript, Tailwind (v2 token classes), Vitest + Testing Library, lucide-react.

**Spec:** `docs/superpowers/specs/2026-10-04-ui-v2-v20261004-design.md` (decisions D27–D43). Per-element values: the `gap-*.md` reports in `docs/superpowers/specs/2026-10-04-ui-v2-v20261004/`. When the gap report and the spec disagree, the spec wins.

## Global Constraints

- May modify only: `components/v2/**`, `app/globals.css` (add v2 tokens only), `tests/**`, `docs/**`.
- Must NOT modify: `components/v1/**`, `components/ui/**`, `components/expense/**`, `components/location-picker.tsx`, `app/api/**`, `prisma/**`, `lib/**`, `tests/components/v1/**`.
- `components/v2/**` must not contain `#hex`, `bg-white`, `text-white`, `bg-black`, or `dark:` (guarded by `tests/components/v2/no-hardcoded-colors.test.ts`; remove the `quick-expense/camera-step.tsx` exemption in Task 6.1).
- Money is formatted with `formatCurrency` → `TWD 1,280` (D17); never `NT$`/`$` in code.
- New files need Lines% ≥ 90; no `components/v2/<folder>` may fall below the M6 baseline (`docs/superpowers/specs/2026-10-03-ui-v2-milestone-6/coverage-baseline.txt`).
- Every task ends green on `npm run lint` and `npm run test:run` before commit.
- v1 guard must print nothing at the end:
  `git diff --name-only 36633e1 -- components/v1 components/ui components/expense components/location-picker.tsx app/api prisma lib/hooks/useExpenseFilters.ts lib/expense-split.ts lib/project-overview.ts lib/trip.ts`

## Review Focus

1. A26 non-equal split — a settlement detail whose participants do not all share equally must list per-member amounts, not `(14000 ÷ 4)`.
2. A12b batch of 1 item vs many — progress dots, position label `1 / N`, per-item editing and the total card must stay correct at both extremes.
3. Calculator pad input — repeated operators, a leading dot, backspace to empty, and Apply on an empty expression must not crash or write NaN.
4. A6b filter chip active + open in the 3-column 390px grid — chip content must not overflow when it shows a badge.
5. A10 camera `mode === "fallback"` (no permissions) and the new A11 選擇圖片 gallery path must still produce an expense item.
6. A8b/A6b empty data — donut/trend and the expense list must show the existing "尚無支出" state, not error.
